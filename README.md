# AI Mock Interview Platform

An AI-powered mock interview simulator designed to help students practice technical interviews through realistic AI-driven conversations and personalized feedback.

## Overview

The AI Mock Interview Platform provides an interactive environment where users can select interview roles, answer AI-generated questions, and receive feedback to improve their interview performance.

The goal of this project is to simulate real-world technical interviews and help users build confidence through continuous practice.

## Features

- Role-based interview selection
- AI-generated technical interview questions
- Multi-turn interview conversations
- AI-based answer evaluation
- Personalized feedback and performance analysis
- Interview session tracking

## Installation and Setup

### Clone the repository

```bash
git clone <repository-link>
```

### Install dependencies

For frontend:

```bash
cd client
npm install
```

For backend:

```bash
cd server
npm install
```

### Run the application

Start the frontend:

```bash
npm run dev
```

Start the backend:

```bash
npm start
```

## Workflow

1. User selects an interview role.
2. The AI generates role-specific interview questions.
3. User provides answers through the platform.
4. AI evaluates responses and provides feedback.
5. A performance summary is generated to help improve future interviews.
